この公開リポジトリは配布専用です。開発コードと D&D❀TikTok のデータは含みません。

## テスト版について
- Android標準の画面共有 (MediaProjection) を使い、端末内で指定範囲の「黄色あり／なし」を判定します。
- ユーザー補助は使いません。通信権限もありません。
- 他のアプリ上への小窓表示、▶／⏸、稼働時間の表示を試せます。
- **黄色い円の回転速度・猫の縮小完了判定・自動スクロールは未実装です。**
- 開発用署名の試験版です。Google Playによる審査・認定は受けていません。**Play プロテクトの警告が出る場合は強行せず、インストールを中断してください。**
- Android側の画面共有や小窓表示の許可は、端末ごとに本人の操作が必要です。すべての端末で動く保証はありません。
- 現在は **まず稼働用 Android 1台だけで動作検証** する段階です。

旧 `app-debug.apk` は **v1.5**（ユーザー補助方式）で、配布停止対象です。使用しないでください。
