## 大切なお知らせ

- これは黄色い領域の画像判定と右上の操作パネルを試すための**実機未検証のテスト版**です。
- **黄色い円の回転判定・猫の縮小検出・自動スクロールは実装していません。**
- Androidのユーザー補助の許可は端末ごとに手動設定が必要です。
- 稼働端末はまず1台だけで、インストールと表示・認識が正しく動くかを確認してください。
- 配布QRは上記APKへの固定URLを指します。次回更新時もファイル名を同じまま入れ替える方式です。
